# HydroFren

Vízivás-emlékeztető Android app vízcsepp-cicával, okos napi céllal, gyógyszer-emlékeztetővel és kezdőképernyő-widgettel.

## APK
Minden `main` ágra feltöltés után a GitHub Actions lefordítja az APK-t. A legfrissebb a **Releases** oldalon tölthető le (`HydroFren.apk`).

## Aláírás
A `keystore/hydrofren-debug.jks` közös fejlesztői kulcs, hogy a felhőben fordított verziók egymásra települjenek. Google Play kiadáshoz külön, titkos kulcs kell, ezt ne használd arra.
